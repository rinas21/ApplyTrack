ApplyTrack Extension

Connection

Configure the ApplyTrack API and authentication. For local development you can paste an access token from the web app session (browser devtools/storage) or use a backend dev bypass only in local environments. Production should use the Keycloak PKCE flow via the applytrack-extension public client.

Security notes

  • Never store Keycloak admin credentials in the extension.
  • Never expose OAuth refresh tokens in extension or frontend code.
  • Use PKCE public clients only.
  • The extension sends captured job data only to the configured ApplyTrack API.
